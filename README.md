
# React Context API

A React project built to learn and practice Context API for sharing state between components without prop drilling.

## 🚀 Features

- React functional components
- Context API for state management
- Share data between components
- Reusable components
- Clean and simple UI

## 🛠️ Technologies Used

- React.js
- JavaScript
- Vite
- Tailwind CSS

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Nareshjena2005/Ls-ContextApi.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Ls-ContextApi
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```
